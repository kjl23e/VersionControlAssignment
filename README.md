Version Control is iteratively saving your work so that you can always refer to a previous save if you mess up the current iteration.

The difference between Git and GitHub is that Git is a local tool and GitHub is the cloud platform that stores your work.

git status shows the status to show if any files have been modified
git add is the first step in uploading a file
git commit -m "" is pairing a comment with the file to describe what was done
git push is the final step that uploads it to GitHub
